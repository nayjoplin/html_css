Envio Rápido API

API para cadastro de envios, validação de CEP, cálculo de frete e notificação via fila.

Endpoints

  • POST /api/envios — cria novo envio
  • GET /api/envios/{id} — consulta envio
  • PUT /api/envios/{id} — atualiza envio
  • PATCH /api/envios/{id}/endereco — atualiza endereço
  • DELETE /api/envios/{id} — remove envio

Documentação

Swagger UI: /docs

OpenAPI JSON: /api-docs

Exemplo de payload (POST /api/envios)

{
  "remetente": {
    "nome": "Empresa Exemplo",
    "cep": "01001000"
  },
  "destinatario": {
    "nome": "Cliente Final",
    "cep": "87020025"
  },
  "pacote": {
    "peso_kg": 1.5,
    "altura_cm": 10,
    "largura_cm": 20,
    "comprimento_cm": 30
  }
}

Execução

Com Docker Compose (recomendado):

cd backend-java
docker compose up --build

Ou local com Maven:

cd backend-java
mvn package
java -jar target/envio-rapido-0.0.1-SNAPSHOT.jar

Variáveis de ambiente

  • MONGO_URI (padrão mongodb://localhost:27017/envio_rapido)
  • RABBITMQ_URL (padrão amqp://localhost)
  • PORT (padrão 3000)
