# Corretora PRO — Frontend (Vite + React)
Front-end completo para apresentar o projeto (lista/kanban/cards, calendário, relatório, conta e suporte). Persistência em localStorage e moeda BRL.

## Rodar local
```bash
npm i
npm run dev
```

## Build/preview
```bash
npm run build
npm run preview
```
